Mettre le site sur l'écran d'accueil de mon téléphone ou de ma tablette

Vous pouvez ajouter ce site sur l'écran de votre téléphone ou de votre tablette, comme une application. Un seul appui, et le site s'ouvre. Rien à télécharger.

Commencez par la page d'accueil du site. Le raccourci ouvrira la page où vous êtes.

iPhone / iPad – Safari

  1. Ouvrez le site dans Safari.
  2. Touchez le bouton Partager (un carré avec une flèche vers le haut), en bas de l'écran.
  3. Faites défiler et touchez « Sur l'écran d'accueil » (parfois caché sous « Plus »).
  4. Touchez « Ajouter ».

iPhone / iPad – Chrome ou Firefox

  1. Ouvrez le site.
  2. Touchez le menu (trois points ou bouton Partager).
  3. Touchez « Ajouter à l'écran d'accueil », puis confirmez.

Android – Chrome

  1. Ouvrez le site.
  2. Touchez les trois points en haut à droite.
  3. Touchez « Ajouter à l'écran d'accueil » (ou « Installer l'application »).
  4. Confirmez avec « Ajouter ».

Android – Samsung Internet

  1. Touchez le menu (trois traits) en bas.
  2. Touchez « Ajouter page à », puis « Écran d'accueil ».

Android – Firefox

  1. Touchez les trois points.
  2. Touchez « Installer » ou « Ajouter à l'écran d'accueil ».

Android – Edge

  1. Touchez les trois points en bas.
  2. Touchez « Ajouter au téléphone », puis choisissez l'écran d'accueil.

Conseils

  • Vous ne trouvez pas l'option ? Vérifiez que vous êtes bien dans le navigateur, et pas dans une autre application (Facebook, Messenger…), qui ouvre les liens dans sa propre fenêtre.
  • Sur iPhone, utilisez de préférence Safari.
  • Pour supprimer l'icône : appui long sur l'icône, puis « Supprimer ».
