# CHAPITRE MODÈLE : copie ce dossier pour créer un nouveau chapitre.
#
# Règles :
# - Les lignes qui commencent par # sont des commentaires : le site les ignore.
# - Les lignes vides sont ignorées.
# - Les colonnes sont séparées par « | ».
# - Un identifiant (id) : minuscules, chiffres et tirets, sans accent ni espace.
#   Il est unique dans le chapitre et ne change plus une fois publié.
# - Le son d'un mot, d'une phrase ou d'une dictée : audio/<id>.m4a
# - L'image d'un mot : images/<id>.png (à ajouter quand tu l'as).

# Le titre du chapitre (obligatoire) :
titre: Titre du chapitre

# Le lien Quizlet (facultatif ; enlève le # pour l'activer) :
# quizlet: https://quizlet.com/...
# Plusieurs listes : une ligne par liste, avec son nom avant « | » :
# quizlet: Les mois | https://quizlet.com/...

# Un conseil pour les parents (facultatif ; enlève le # pour l'activer) :
# note_parents: Écrivez ici votre conseil.

# Sur les cartes, le français écrit sous le dessin (facultatif ; enlève le # pour l'activer) :
# cartes_francais: oui

# Exercice « Couleurs » (facultatif ; enlève le # pour l'activer) : « De bus is rood. »
# Les dessins SVG de Claude dont une partie est marquée class="teinte" sont repeints
# dans les couleurs du chapitre indiqué ici (son nom de dossier).
# couleurs: kleuren

# Le monstre du jeu « Le combat de boss » (facultatif ; enlève le # pour l'activer) :
# son nom, et son dessin boss.svg (ou boss.png) dans le dossier du chapitre.
# Sans cette ligne, il s'appelle « le monstre » ; sans dessin, une forme simple le remplace.
# boss: Gribouille

# Le décor du combat de boss (facultatif ; enlève le # pour l'activer) : le nom de ses deux
# images dans le dossier commun contenu/arene/ (couleurs.jpg et couleurs-difficile.jpg),
# sans « .jpg ». Deux chapitres, même de langues différentes, peuvent partager un décor.
# arene: couleurs

# Chapitre de révision (facultatif ; enlève le # pour l'activer) : les chapitres dont il
# reprend tout (mots, phrases, pistes, dictées, Mots en ordre, Qui est-ce ?), noms de dossiers
# séparés par des virgules. Rien n'est copié : sons et images restent dans leur chapitre.
# À chaque partie, autant de mots de chaque chapitre ; « Je découvre » : une liste par chapitre.
# Les sections ci-dessous peuvent alors rester vides.
# reprend: kleuren, vervoermiddelen, verjaardag


[mots]
# id | mot (avec l'article pour un nom : de, het) | français | indice (facultatif)
# Exemples :
# pet | de pet | la casquette
# hemd | het hemd | la chemise | hemd.svg
# zeven | zeven | sept | texte:7
# rood | rood | rouge | couleur:red
# L'indice (4e colonne) est ce que montre l'autre face de la carte :
#   hemd.svg      une image du dossier images/ (sans 4e colonne : images/<id>.png, si elle existe)
#   texte:7       « 7 » écrit en très grand
#   couleur:red   un carré rouge. Couleurs : red, orange, pink, yellow, black, green,
#                 purple, blue, white, gray, brown, ou un code comme couleur:#C62828
# Sans indice, l'autre face montre le français. Avec un indice, le français n'est
# pas affiché : tu peux laisser la 3e colonne vide (rood | rood | | couleur:red).
# Listes de « Je découvre » (facultatif) : une ligne « liste: » avant un groupe de mots.
# Les mots qui suivent forment une liste, jusqu'à la ligne « liste: » suivante. Exemple :
# liste: Les mois

[phrases]
# id | phrase | français | mot à masquer (facultatif) | autres propositions (facultatif)
# Cartes (facultatif) : une ligne « cartes: Je me présente » ; les phrases suivantes deviennent les cartes
# de cette liste dans « Je découvre » (devant la phrase et sa voix, au dos le français).
# Pour la placer entre deux listes : écris aussi « liste: Je me présente », sans mot, à sa place dans [mots].
# Listes (facultatif) : une ligne « liste: » avec le nom exact d'une liste de [mots] ;
# les phrases qui suivent s'affichent dans « Je découvre » avec cette liste.
# Une phrase sans liste s'affiche avec toutes les listes.
# Dessin : chaque phrase reçoit un dessin de son sens, images/<id>.svg (même nom que la phrase),
# montré au-dessus d'elle dans les exercices (textes à trous, phrases en désordre, Mots en ordre).
# Exemple :
# p1 | Ik draag een rode pet. | Je porte une casquette rouge. | rode

[pistes]
# id | titre | texte (facultatif) | français (facultatif)
# Un enregistrement joué en entier, comme modèle d'écoute.
# Exemple :
# savoir-se-presenter | Savoir se présenter

[dictees]
# id | titre | texte de la dictée (= la correction ; « / » = retour à la ligne) | français (facultatif)
# Exemple :
# dictee-1 | Dictée 1 | Ik heet Lina. / Ik ben acht jaar.
# Dictée de dates tirées au hasard (pas de son à enregistrer) : écris « dates: » en 3e colonne.
# Il faut, dans [mots] et avec leur son, des jours (maandag…), des mois (januari…) et les nombres 1 à 31 (texte:1…).
# dates | Les dates | dates:

[ordre]
# id | cases séparées par « / » | son à écouter (facultatif : l'identifiant d'un audio du chapitre) | intrus (facultatif)
# Jeu « Mots en ordre » de « Je m'entraîne » : l'enfant remet les cases dans le bon ordre.
# Ce qui est entre deux « / » forme une seule case. Une ligne = une manche (au moins 2 cases).
# Dessin : celui de la phrase du son de la 3e colonne ; sinon images/<id de la manche>.svg s'il existe.
# Le son de la 3e colonne : s'il sert à une seule manche, il est joué juste après elle ;
# s'il sert à plusieurs manches, il est proposé à la fin (« Écoute tout le texte »).
# Intrus : un ou plusieurs mots en trop, séparés par des virgules, mélangés avec les cases ;
# l'enfant doit les laisser de côté. Prends un mot du vocabulaire du chapitre (pas is, zijn, de, het).
# Si la 3e colonne est vide, écris « | | » avant l'intrus.
# Exemples :
# presenter-1 | Ik / ben / een jongen (of meisje) | savoir-se-presenter
# zin-4 | Er / is / een / kast. | school-p8 | stoel
# dagen | maandag / dinsdag / woensdag / donderdag / vrijdag / zaterdag / zondag | | juli

[descriptions]
# id | texte de la description (« / » = nouvelle phrase) | français (facultatif)
# Jeu « Qui est-ce ? » de « Je joue » : l'élève écoute et lit la description d'une personne,
# puis la retrouve parmi 4 dessins. Il faut au moins 3 descriptions.
# Pour chacune : le son audio/<id>.m4a et le dessin images/<id>.png (une personne en pied, fond uni).
# Exemple :
# description-a | Hij is groot en slank. / Hij draagt een bril. | Il est grand et mince. Il porte des lunettes.

[fin-de-phrase]
# id | début de la phrase | bonne fin | autres propositions (séparées par des virgules) | identifiant d'un mot de [mots]
# Exercice « Het is… » de « Je m'entraîne » : une image, le début de la phrase, l'élève choisit la bonne fin.
# Le mot de la 5e colonne donne l'image, et son son est joué après la réponse.
# Exemple :
# fin-1 | Het is | zonnig. | koud., mistig. | het-is-zonnig

# ---------- Chapitres de grammaire (année « grammaire » dans catalogue.txt) ----------
# Mots mis en couleur dans « Je comprends » (facultatif, en haut du fichier, avant [mots]) :
# en_couleur: am, is, are       (une couleur par mot ; « -ing » colore tout mot qui finit par -ing)
# Ces mots donnent aussi l'ordre des boutons de « Je trie » et de « J'écoute et je clique ».

[explication]
# Rubrique « Je comprends », avant « Je découvre » : une page d'explication en français.
# Chaque ligne commence par son type :
#   titre | texte                                     un sous-titre
#   texte | texte                                     un petit paragraphe
#   tableau | case | case | ...                       une ligne de tableau (la 1re ligne = en-tête)
#   exemple | anglais | français | son (facultatif)   un exemple, avec son bouton d'écoute si le son existe
#   astuce | texte                                    un encadré « Astuce »
# Exemple :
# titre | « To be » veut dire « être »
# exemple | I am from Belgium. | Je viens de Belgique. | tobe-p1

[tri]
# id | mot ou phrase | boîte
# Exercice « Je trie » de « Je m'entraîne » : chaque mot (ou phrase) se range dans sa boîte.
# Les boîtes sont les valeurs de la 3e colonne (2 à 4). Un dessin images/<boîte>.svg remplace le mot (smileys).
# Exemple :
# sort-1 | my mum | is

[pronoms]
# id | phrase | sujet à remplacer | bon pronom | autres propositions (séparées par des virgules)
# Exercice « Le bon petit mot » de « Je m'entraîne » : la phrase, puis la même avec un trou à la place du sujet.
# Exemple :
# pronoun-1 | My mum is tall. | My mum | She | He, It, They

[paires]
# id | carte 1 | carte 2
# Jeu « Le memory des paires » de « Je joue » (au moins 3 lignes). Deux cartes vont ensemble si elles forment
# une ligne du fichier : une carte « is » va donc avec he, she et it.
# Exemple :
# pair-3 | he | is

[ecoute]
# id d'une phrase de [phrases] | bonne réponse
# Exercice « J'écoute et je clique » de « Je m'entraîne » : l'élève écoute la phrase et touche la bonne réponse
# (2 à 4 réponses différentes ; un dessin images/<réponse>.svg remplace le mot).
# Sans cette section, l'exercice se fait seul avec les phrases à trou qui ont un son, si leurs mots
# à masquer forment 2 à 4 boutons (am / is / are).
# Exemple :
# sports-p2 | like
